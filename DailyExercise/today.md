## 主线

### 1. 基础计算｜一阶线性微分方程

在 $x>0$ 上求通解：

```math
y'+\frac{1}{x}y=x^2
```

**考察点：** 积分因子、乘积导数结构、通解常数项。

### 2. 概念辨析｜极限方法选择

判断下列说法是否正确；若错误，说明原因或给出反例。

1. 若 $f(x)\sim g(x)$（$x\to0$），则 $e^{f(x)}-1\sim e^{g(x)}-1$。
2. 若 $f(x)\sim g(x)$（$x\to0$），则 $1+f(x)\sim1+g(x)$。
3. 若 $f(x)=o(x)$（$x\to0$），则 $f(x)/x\to0$。

**考察点：** 等价无穷小的使用边界、小 $o$ 定义。

### 3. 综合题｜二重积分与极坐标

设

```math
D=\{(x,y)\mid x^2+y^2\le2y\}
```

计算

```math
\iint_D(x^2+y^2)\,dx\,dy
```

**考察点：** 偏移圆、极坐标区域、面积元。

### 4. 证明题｜中值定理

设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0)=0,f(1)=1$。证明存在 $\xi\in(0,1)$，使

```math
f'(\xi)=2\xi
```

**考察点：** 目标导数形式、辅助函数、中值定理选择。

### 5. 压轴思维题｜条件极值

求

```math
f(x,y)=x^2y
```

在约束

```math
x^2+y^2=3
```

下的最大值、最小值及相应点。

**考察点：** Lagrange 乘数法、候选点完整性、函数值比较。

### 6. 夹逼型极限

求

```math
\lim_{x\to0}x^2\sin\frac{1}{x}
```

并说明方法。

**考察点：** 夹逼准则、有界因子与无穷小。
