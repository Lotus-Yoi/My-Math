### 1. 基础计算｜二阶常系数非齐次微分方程

求微分方程的通解：

```math
y''-3y'+2y=e^x+x
```

**考察点：** 齐次通解、待定系数法、指数项与齐次解撞车、多项式特解补全。

### 2. 概念辨析｜等价关系的使用边界

判断下列命题是否正确；若错误，说明原因或给出反例。

1. 若 $f(x)\sim g(x)$ 且 $f(x)\to0$（$x\to0$），则
```math
e^{f(x)}-1\sim e^{g(x)}-1
```

2. 若 $f(x)\sim g(x)$（$x\to0$），则
```math
f(x)+x\sim g(x)+x
```

3. 若 $f(x)\sim g(x)$ 且 $g(x)\to0$（$x\to0$），则
```math
\sin f(x)\sim g(x)
```

**考察点：** 等价无穷小的成立条件、加减法中的等价替换、复合等价关系。

### 3. 综合题｜二重积分与偏移圆

设

```math
D=\{(x,y)\mid x^2+y^2\le 2x\}
```

计算

```math
\iint_D (x^2+y^2)\,dx\,dy
```

**考察点：** 偏移圆的极坐标定限、$r$ 上限、面积元。

### 4. 证明题｜拉格朗日中值定理

设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且 $f(0)=0$、$f(1)=1$。证明：存在 $\xi\in(0,1)$，使

```math
f'(\xi)=\frac{1}{1+\xi}
```

或判断上述结论是否一定成立；若不成立，请说明理由并给出反例。

**考察点：** 先判断结论是否由条件保证、避免机械构造辅助函数、中值定理条件检查。

### 5. 压轴思维题｜二阶微分方程初值问题


**考察点：** 重根通解、初始条件、通解到特解。
