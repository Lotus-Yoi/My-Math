## 第三章｜一元函数积分学

**状态：正在第一轮学习**

目前已经学习：

- 原函数与不定积分的基本思想
- 基本积分：把积分理解为“寻找这个导数对应的原函数”
- 第一类换元法的基本思想
- 不定积分中的换元
- 分部积分的来源：乘积求导公式的逆用
- 定积分的基本概念与上下限
- 定积分换元
- 牛顿—莱布尼茨公式的基本理解
- 定积分的对称性 / 奇偶性初步应用
- 变上限积分
- 变限积分求导
- 上下限均为函数时的求导：
  \
  \[
  \left[\int_{g(x)}^{h(x)}f(t)\,dt\right]'
  =f(h(x))h'(x)-f(g(x))g'(x)
  \]

当前正在形成的模式识别：

- 看到 \(f(g(x))g'(x)\) 型结构，尝试换元 \(u=g(x)\)
- 换元时不仅替换函数内部，还要同步替换 \(dx\) 对应的微分部分
- 变限积分可以理解为“上限贡献 − 下限贡献”，本质是微积分基本定理与链式法则
