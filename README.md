### 定积分

- 定积分概念

### 变限积分

已掌握：

- 变上限积分求导
- 上下限均为函数时的求导

公式：

$$
\left[\int_{g(x)}^{h(x)}f(t)dt\right]'
=f(h(x))h'(x)-f(g(x))g'(x)
$$

当前掌握特点：

- 能理解变限积分本质为“上限贡献减去下限贡献”
- 能通过链式法则处理复杂上下限
- 已建立定积分与中值定理之间的联系
